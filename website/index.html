bench-netdata

stable

Structured access to Netdata monitoring data. CPU, RAM, disk, network, alarms, chart history. Any Netdata instance, anywhere.

10 tools (all read) Connects to Netdata npx @glassmkr/bench-netdata
Read Tools (10)
get_server_overview
Hostname, OS, uptime, CPU count, total RAM, Netdata version.
get_cpu_usage
CPU utilization breakdown and load averages.
Input: period_seconds (optional, default 60)
get_memory_usage
RAM and swap usage in MB and percent.
get_disk_usage
Disk space for all mounted filesystems.
Input: mount_point (optional)
get_disk_io
Read/write rates per device.
Input: device (optional), period_seconds (optional)
get_network_traffic
Interface traffic: sent and received.
Input: interface (optional), period_seconds (optional)
get_chart_data
Raw time-series data from any Netdata chart. The power tool.
Input: chart (required), after, before, points
list_charts
Lists all available charts on the Netdata instance.
Input: filter (optional)
get_alarms
Active warnings and criticals.
Input: status (optional: warning, critical, all)
get_alarm_log
Recent alarm transitions.
Input: last_n (optional, default 20)

All nodes with CPU, memory, uptime.
list_vms

get_vm

list_containers
All LXC containers.

Quick Start

Add to your MCP client config (Claude Code, Cursor, etc.)
{
  "mcpServers": {
    "netdata": {
      "command": "npx",
      "args": ["@glassmkr/bench-netdata"],
      "env": {
        "NETDATA_URL": "http://your-server:19999"
      }
    }
  }
}

Philosophy

Named after the glassblower's workbench. Every tool forged for a specific purpose, tested in production, open source. Read tools execute freely. Write tools require explicit confirmation. Credentials stay in environment variables, never in MCP messages. Learn more about Glassmkr.
